 라이브러리  `requirements.txt` 파일로 한 번에 저장해 주는 아주 유용한 명령어가 있습니다.

터미널(또는 VS Code의 프롬프트 창)에서 해당 프로젝트 폴더로 이동한 뒤 아래 명령어를 입력해 보세요.

### 1. 라이브러리 목록 저장 명령어

```bash
pip freeze > requirements.txt

```

이 명령어를 실행하면 현재 사용 중인 파이썬 환경에 설치된 모든 라이브러리와 그 버전 정보가 자동으로 `requirements.txt` 파일에 기록됩니다.

### 2. 특정 라이브러리만 깔끔하게 관리하고 싶다면?

`pip freeze`는 현재 환경에 설치된 **모든** 라이브러리를 가져오기 때문에, 때로는 프로젝트와 상관없는 정보까지 들어갈 수 있습니다. 만약 사용자님의 `medipin`이나 `스케줄 관리 앱`에 실제로 사용된 라이브러리만 추출하고 싶다면 **`pipreqs`**라는 도구를 추천합니다.

* **설치:** `pip install pipreqs`
* **실행:** `pipreqs . --encoding=utf-8` (현재 폴더에 있는 `.py` 파일들을 분석해서 필요한 것만 담아줍니다.)

---

### 3. 나중에 다시 설치할 때는?

나중에 이 파일을 이용해 다른 곳(예: Render 서버)에서 라이브러리를 그대로 다시 설치할 때는 아래 명령어를 사용합니다.

```bash
pip install -r requirements.txt

```

### 💡 팁

사용자님의 프로젝트가 **FastAPI** 기반이라면, `requirements.txt` 파일 안에 아래와 같은 항목들이 들어있는지 확인해 보세요.

* `fastapi`
* `uvicorn`
* `pymysql` (또는 `mysql-connector-python`)
* `sqlalchemy` (DB 라이브러리를 쓰시는 경우)

명령어를 실행했는데 파일 내용이 이상하거나, 실행 중에 오류가 나면 언제든 말씀해 주세요!
